## 一、现状诊断

当前页面"AI 味"重、样式对不齐，根因有五条（行号基于 `travel_assistant/static/index.html`）：

### 1. 配色是 AI 模板脸重灾区

紫蓝渐变 hero + 渐变胶囊按钮 + 玻璃拟态（`backdrop-filter`），是当前 AI 生成页面最高频的默认组合。

- `:10` `--bg-main: linear-gradient(135deg, #4457cf, #6359c7, #7c57c1)`
- `:26` `--gradient: linear-gradient(90deg, #5f71e3, #8758c6)`（按钮、标签、进度条全用它）
- `:120` `backdrop-filter: blur(10px)`（玻璃拟态）
- `:64-85` hero 上的两个浮动装饰圆

### 2. 控件是"三个物种"

同一张表单里三种控件语言并存，这是"对不齐"观感的主要来源：

| 控件 | 现状 |
|---|---|
| `input` | 自定义白底圆角（`:184-194`） |
| `select` | **浏览器原生灰底样式**（截图中"智能推荐""舒适型酒店"灰条），未做任何样式覆盖 |
| "旅行天数" | 渐变 pill（`:203-211`），与白色输入框并排时视觉跳动 |

另外：number 输入框露出原生上下箭头（截图中"3000"右侧）；checkbox 是原生小方框 + emoji 混排。

### 3. 栅格列宽故意不等，间距体系混乱

- `:160` `grid-four: 1.25fr 1fr 1fr 0.6fr` —— 四列输入框长短不一
- 卡片 padding 18/20px 与 shell padding 18px 多层叠加
- `section-title::after`（`:144-150`）用半透明渐变线分隔，粗糙
- hint 文案溢出卡片（截图 2 中"虹桥小…"被截断）

### 4. 没有字体系统

- 全站仅 body 一条系统字体栈（`:42`），无任何字体层级设计
- 字号 56 / 28 / 22 / 18 / 15 / 14 / 13 / 12 随意散布，无比例关系
- 字重 700 / 800 / 900 混用
- 日期、金额、编号等数据与中文正文共用同一字体渲染 → 用户感知的"字体不一样"

### 5. emoji 当图标

✈️📍⚙️💬🏨（`:1583`、`:1590`、`:1613`、`:1671`）各平台渲染不一致，廉价感重灾区。

## 二、设计方向：「旅行票据」

方法论：从"旅行"这件事的真实物料里提取视觉语言——登机牌、火车票、检票章、行李牌——而不是套通用 SaaS 模板。红蓝票据配色是中国用户对"出行"的集体记忆，辨识度极高。

### 2.1 设计原则

1. **零渐变、零玻璃拟态、零 emoji 图标**（装饰圆全删）
2. **一种控件语言**：所有输入控件白底 + 统一描边 + 统一圆角
3. **数据用等宽字体**：日期、天数、金额、编号一眼可辨
4. **克制用色**：印章红只做点缀（印章、关键状态），不铺大面积

### 2.2 色彩 Tokens

| Token | 值 | 用途 |
|---|---|---|
| `--paper` | `#F6F7F9` | 页面底色（冷白纸感） |
| `--card` | `#FFFFFF` | 卡片面 |
| `--rail-blue` | `#1B4ED8` | 主行动色（按钮、链接、激活态、数据强调） |
| `--stamp-red` | `#D93A2B` | 检票章、关键标记（仅点缀） |
| `--ink` | `#16181D` | 正文 / 标题 |
| `--muted` | `#6B7280` | 辅助文字、占位符 |
| `--line` | `#E3E6EB` | 描边、分隔线 |

### 2.3 字体系统

| 角色 | 字体 | 规格 |
|---|---|---|
| 标题 | **得意黑（Smiley Sans）**——当前机器获取渠道全断（见 P1 前置），**降级方案先行**：苹方 700 + `letter-spacing: -0.02em`；`@font-face` family 名先占住 `"Smiley Sans"`，字体文件后补时仅替换 src | 仅页面主标题 / 结果页大标题，克制使用 |
| 正文 | PingFang SC / 思源黑体 / 系统栈 | 14px / 1.6 |
| 数据 | **IBM Plex Mono**（等宽，`@fontsource/ibm-plex-mono` jsdelivr 可达，woff2 下载至 `static/fonts/` 本地打包） | 日期、天数、金额、票号、统计数字 |

字重收敛（P1 执行，纯替换）：800 → 700（24 处）、900 → 700（6 处），最终只用 400 / 500 / 700 三档。
字号收敛（**拆到 P2/P3 逐屏定**，不在 P1 一刀切）：现状 12 档（12/13/14/15/16/18/22/28/30/40/56/64px），目标 5 级 `12 / 14 / 16 / 18 / 24`（主标题除外）。优先合并 13px（18 处）与 12px（12 处）为一档——两档占全部字号声明近一半，合并后改动量立减约 60%。结果页信息密度高（预算卡/地图/轨迹/按天卡），正文字号逐屏试读后再定，不预设 14px。

### 2.4 签名元素（Signature）：票根

结果页头卡做成一张**票根**，这是整站唯一的"记忆点"，其余部分保持安静：

```
┌──────────────────────────────────────────────┬──────────┐
│  ┌──────┐                                     │          │
│  │已出票 │  TRIP NO.                          │   │││    │
│  └──────┘  TRIP-20261008-PEK                 │   │││││   │
│            上海 → 北京        3 DAYS   ¥3000   │   │││    │
├╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌┤  条码   │
│           （打孔分隔线 + 半圆缺口）              │          │
└──────────────────────────────────────────────┴──────────┘
```

- 打孔线：`border-top: 2px dashed`（不占渐变白名单）+ 两端半圆缺口（`radial-gradient` 背景圆）【渐变白名单 #2】
- 印章："已出票"红框小标签，旋转 -4°
- 票号规则：`TRIP-{出发日期}-{目的地城市名}`（如 `TRIP-20261008-上海`），由现有渲染模板字符串生成。不引入城市→三字码映射（后端无此字段，避免新增 JS 逻辑）；票据感由打孔线 + 等宽字承担，不依赖 IATA 码。
- 条码：纯 CSS 重复线性渐变即可（不需要图片）。【渐变白名单 #1】

### 2.5 着陆页：「旅行委托单」概念

删掉大渐变 hero，整页就是一张委托单：

```
┌─────────────────────────────────────────────┐
│  智能旅行助手          （得意黑，24px，左对齐） │
│  填好这张委托单，剩下的交给规划引擎。            │
│                                             │
│  ┌ 01 行程 ──────────────────────────┐      │
│  │ [目的地城市] [开始日期] [结束日期] [天数]│  ← 四列等宽 1fr
│  └───────────────────────────────────┘      │
│  ┌ 02 偏好 ──────────────────────────┐      │
│  │ [出发城市] [总预算]  [交通方式]      │      │
│  │ [住宿偏好] [期望位置] [住宿连续性]    │      │
│  │ 兴趣： (历史文化)(自然风光)(美食)...  │  ← chip 标签
│  └───────────────────────────────────┘      │
│  ┌ 03 备注 ──────────────────────────┐      │
│  │ [额外要求 textarea]                │      │
│  └───────────────────────────────────┘      │
│                                             │
│  ┌──────── 生成旅行计划（单色蓝）────────┐   │
│  └─────────────────────────────────────┘   │
└─────────────────────────────────────────────┘
```

要点：

- section 标题改为"编号 + 名称"（01 行程 / 02 偏好 / 03 备注），委托单/票据的填表语感；编号真实表达"这是一个有顺序的流程"，不是装饰
- 所有栅格改等宽 `repeat(n, 1fr)`，彻底消除列宽不齐
- 主按钮单色 `--rail-blue`，直角小圆角（8px），不再用胶囊渐变

### 2.6 控件统一规范（P1 核心）

| 控件 | 规范 |
|---|---|
| input / select / textarea | 白底、1px `--line` 描边、8px 圆角、高 44px、focus 时描边变 `--rail-blue` + 3px 蓝色光晕 |
| select | **自定义外观**：`appearance: none` + 背景 SVG 下拉箭头，与 input 视觉一致 |
| checkbox 兴趣组 | 改为 chip：圆角 999px 描边小标签，选中态蓝底白字 |
| number | `appearance: textfield`，隐藏原生上下箭头 |
| 旅行天数 | 白底只读框，等宽字体，与其他输入框等高 |
| 按钮 | 单色蓝 / 白底描边两种，8px 圆角 |

### 2.7 对比度定稿（WCAG 实测，v1.2 新增）

| 组合 | 对比度 | 判定 |
|---|---|---|
| `--ink` / 白 | 17.76 | ✅ AAA |
| `--rail-blue` / 白 | 6.71 | ✅ AA |
| `--muted` / 白 | 4.83 | ✅ AA 小字 |
| `--stamp-red` / 白 | 4.57 | ⚠️ 压线 |
| `--stamp-red` / 纸底 | 4.27 | ❌ 低于 AA 小字 4.5 |

**印章规范（定死）**：印章一律**红底白字**（白字对红底 4.57，过 AA）；若用红字，必须 **≥14px 且字重 700**（属 WCAG 大字文本，3:1 即达标）。原方案"红框小标签"未定义文字颜色，按本条执行。
