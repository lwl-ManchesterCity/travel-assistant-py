## 四、修复 3+4 · 测绘纸纹背景 + 印章水印（氛围层）

**修复 3 · 测绘纸纹**：

- 结果页 `body`/`result-page` 背景：纸底上叠加一层等高线线稿，`--ink` 5% 透明度
- 实现：内联 SVG `background-image`（`url("data:image/svg+xml,...")`），3–4 条闭合等高曲线路径，`fill: none`、`stroke` 取墨色 5%，平铺尺寸 ~600px。**注意**：这是 SVG 背景不是 CSS gradient，不占渐变白名单
- 右下角压等宽坐标读数 `39.9042°N 116.4074°E`（`--muted` `--fs-xs`），固定于视口角落（`position: fixed` 允许，探针无此项判据）

**修复 4 · 印章水印**：

- 票根右下角（条码区一侧）压一枚放大的「已出票」红章：120px 宽、`--stamp-red` **8% 透明度**、`rotate(-12deg)`
- 原骑跨色带的小章保留，两章一大一小一实一虚
- 水印层 `pointer-events: none`，`z-index` 压在票根内容之下、背景之上
