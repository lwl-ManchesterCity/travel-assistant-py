## 二、修复 1 · 联票上线路色

位置：每日联票券（BOLD_VISUAL 修复 2 的结构）。

- 券左缘加 **4px 线路色竖条**（`border-left: 4px solid var(--line-*)`，或 inset box-shadow，不挤占内容宽度）
- `DAY n` 徽标改**线路色底白字**：圆角 `var(--radius-sm)`、`padding: 2px 8px`、等宽粗体——从"蓝字"升级为"线路徽章"，地铁图语言
- 券间打孔线、迷你检票章、条码维持原样（红章仍是红色，不随线路色变化——印章语义不动）
- 线路色按 DAY 序号取模循环：`day1=蓝 day2=祖母绿 day3=琥珀 day4=青 day5=蓝 …`

## 三、修复 2 · 分区物料（封顶两种，克制）

给两个 section 各配一种旅行物料形态，**只允许这两种，不扩散**：

1. **酒店卡 → 行李牌**：卡面左上角做直径 12px 圆孔（纸底色圆 + 1px 描边）+ 孔向右上一段 20px 虚线"挂绳"；卡片整体 `rotate(-0.5deg)` 微斜（真挂牌从不端正），hover 回正。酒店名等宽粗体，房型的信息用小字标签
2. **餐饮卡 → 餐券**：卡片上下边改锯齿边（`linear-gradient` 三角齿纹，**属装饰渐变——加白名单选择器 `.meal-ticket`**，同步更新探针 `GRADIENT_WHITELIST`），券面左侧菜品名、右侧等宽价格，中间 1px dashed 竖撕线

其余 section（天气、地图、轨迹等）维持现状白卡，不加物料——物料超过两种就是杂货铺。

## 四、修复 3（可选）· 地图日路线同色

若高德地图路线渲染支持按段配色：第 n 天的路线 polyline 用对应线路色。不支持或改动侵入地图逻辑则**放弃本项**，在 PR 说明中注明即可，不算验收失败。
