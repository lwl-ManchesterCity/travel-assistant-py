# 结果页色彩补强 ·「一个主色块 + 语义色点缀」

> 对象：执行前端重构的 agent
> 前置：P0–P3 + 着陆页反馈单已执行；「出票」动效单（FRONTEND_FEEDBACK_CREATIVE_MOTION.md）若已开工，本单与其兼容——票根滑出入场保持不变，只改票根静态视觉
> 依据：`docs/FRONTEND_REDESIGN_PLAN.md` v1.3 沿用；不新增色彩 token，全部取现有值
> 问题判定：纠"AI 味"纠过头——结果页只剩白卡 + 灰线 + 小字，无色彩锚点，用户观感"太平淡"。真实票据（登机牌色带、火车票红底）恰恰敢用色块，本单把这一个色块找回来

---

## 一、色彩配额（本单的硬约束，先读）

1. **全页彩色块只允许一个**：票根顶部铁路蓝色带（见修复 1）
2. **语义色封顶三种**：蓝（`--rail-blue`，行动/链接/数据强调）、红（`--stamp-red` / `--stamp-red-ink`，印章/警告）、绿（`--ok-green`，健康状态）——**禁止出现第四种彩色**
3. 除色带外，其余区域保持现有白卡 + 纸底，不加底色块、不加边框色

---

## 二、修复项（共 3 项，全部在 result.css + 结果页模板）

### 修复 1 · 票根顶部色带（全页视觉重锤）

位置：结果页票根头卡（hero-summary-card 对应结构）。

- 票根顶部加一条 **64px 高 `--rail-blue` 纯色带**，占满票根宽度，圆角只带上侧两角（与票根圆角一致）
- 色带内白色文字，左中右三段：
  - 左：`上海 → 北京`，得意黑（`--font-title`）28px，白色
  - 右：`3 DAYS · ¥2723`，`--font-mono` `--fs-md` `--fw-bold`，白色（数据取现有渲染字段）
- 「已出票」红章**骑跨色带下缘**：章的垂直中心对齐色带底边（`margin-top: -14px` 之类），一半压蓝带一半压纸面，`rotate(-4deg)` 不变——真印章就是跨边界盖的
- `TRIP NO.` 行移到色带下方纸面区，保持现状等宽样式
- 对比度：白字压 `--rail-blue` = 6.71 AA（方案 §2.7 已验）
- 与「出票」第 3 幕兼容：色带是票根的一部分，随票根整体滑出，不单独做动效

### 修复 2 · meta 卡数据大字化

位置：票根下方四张 meta 卡（出行日期 / 交通策略 / 预算状态 / 通勤规模）。

- 值：`--font-mono`、20px、`--fw-bold`、`--ink`（现为小灰字，读不到重点）
- 标签：维持 `--fs-xs` `--muted`，但加 `letter-spacing: 0.08em`、全大写风格（中文则加宽字距即可）
- 「预算状态」的值走语义色：健康 → `--ok-green`（对白 5.43 AA，已验）；偏紧 → `--stamp-red-ink`（6.41 AA，已验）。颜色判断逻辑沿用现有 warn/ok class，只改色值映射
- 卡内垂直节奏：标签在上、值在下，间距 `--sp-2`

### 修复 3 · 侧导航激活态加重

位置：侧导航 `.nav-item.active`。

- 现状蓝色块保留，左侧再加 3px `--rail-blue` 竖条（`box-shadow: inset 3px 0 0 var(--rail-blue)` 或直接 border-left），与色带呼应
- 其余导航项不动
